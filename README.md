# lotto - 구현 기능 정리

## View
### InputView
- 기능 구현
    - [ ] 구입 금액을 입력받는다.
    - [ ] 당첨 번호를 입력받는다.
    - [ ] 보너스 번호를 입력받는다.
- 예외 처리
    - [ ] 1,000원 단위가 아니면 예외

### OutputView
- 기능 구현
    - [ ] 랜덤 생성된 로또 리스트 출력
    - [ ] 로또 결과 출력

---

## Domain
### Lotto
- 기능 구현
    - [ ] get으로 정보 가져오는 것
    - [ ] toString으로 전체 string 출력
- 예외 처리
    - [ ] 로또 번호 범위가 1~45 사이인지 예외 처리
    - [ ] 로또 번호 갯수가 6개인지 예외 처리
    - [ ] 중복 숫자 있으면 예외 처리 : Set 사용

### Rank (ENUM)
- 기능 구현
    - [ ] none 부터 1등까지 역순으로 순서
    - [ ] name, 맞는 갯수, 보너스 여부, 금액으로 이뤄져 있다.
    - [ ] 등수 (해당하는 enum) 내보내는 로직이 있다.

### WinningNumber
- 기능 구현
    - [ ] lotto와 bonusNum을 가진다.
    - [ ] bonusNum이 1~45 사이의 숫자인지 검증
    - [ ] getter 존재

---

## DTO
### ResponseDto
- 기능 구현
    - [ ] 꼴지부터 통계 숫자와, 총 수익률을 매개변수로 가진다.
    - [ ] of (정적 팩토리 메서드)를 통해 enum의 문자로 변경해서 저장

---

    - [ ] 빈칸이 있을 경우 예외
